# getfixbook.com

The Fixbook website. Static HTML and CSS, served by GitHub Pages. Push to main and it is live in about a minute.

- `index.html` the front door: what Fixbook is, and Sign in (to app.getfixbook.com).
- `security/`, `privacy/`, `terms/` short plain pages. Company details live in the footer of every page.
- `login/` redirects to the app's sign-in.
- Fonts are self-hosted in `fonts/` (Schibsted Grotesk, IBM Plex Mono), so no request leaves for Google.
- Rules carried from Staffbook: no em dashes, no "AI", plain words, no prices, examples use invented sites.
